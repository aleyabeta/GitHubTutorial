CONTROL DE VERSIONES

Dominá Git y GitHub

Aprendé a controlar las versiones de tus proyectos, guardar cambios y colaborar con otros desarrolladores.

Comenzar a aprender

¿Qué es Git?

Git es un sistema de control de versiones distribuido. Permite registrar cambios en archivos, consultar versiones anteriores y trabajar en diferentes ramas.

📁

Control de versiones

Registrá los cambios realizados en tu código y consultá el historial del proyecto.

🌿

Ramas

Desarrollá nuevas funcionalidades de manera independiente utilizando branches.

↩

Recuperación

Consultá versiones anteriores y revertí cambios cuando sea necesario.

¿Qué es GitHub?

GitHub es una plataforma que permite alojar repositorios Git en internet y colaborar con otros desarrolladores.

☁

Repositorios remotos

Almacená y compartí tus proyectos online.

👥

Colaboración

Trabajá con compañeros mediante ramas, issues y pull requests.

🔍

Revisión de código

Revisá las modificaciones antes de integrarlas a la rama principal.

Comandos esenciales

Estos son algunos de los comandos más utilizados durante el desarrollo de un proyecto.

git init

Inicializa un repositorio local.

git status

Muestra el estado de los archivos.

git add .

Prepara los cambios para un commit.

git commit -m "mensaje"

Registra los cambios preparados.

git push

Sube los commits a un repositorio remoto.

git pull

Obtiene e integra cambios del remoto.

git clone URL

Clona un repositorio existente.

git switch -c nueva-rama

Crea una rama y cambia a ella.

Flujo de trabajo

Seguí estos pasos para registrar y publicar tus cambios en GitHub.

01

Modificar

Editá los archivos de tu proyecto.

02

Preparar

git add .
03

Registrar

git commit -m "Cambio"
04

Publicar

git push

Ejemplo: publicar un proyecto nuevo

Después de crear un repositorio vacío en GitHub:

git init
git branch -M main
git add .
git commit -m "Primer commit"
git remote add origin URL_DEL_REPOSITORIO
git push -u origin main

Reemplazá URL_DEL_REPOSITORIO por la dirección real de tu repositorio de GitHub.
